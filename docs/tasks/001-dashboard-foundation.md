# Task: Dashboard Foundation

## Status

Ready

## Goal

Create the initial Project Dashboard UI and project data model.

## Requirements

- Replace the default Vite starter UI.
- Create a dashboard page with:
  - app title
  - short subtitle
  - project count
  - responsive project-card grid
- Create a project data structure containing:
  - id
  - name
  - description
  - status
  - priority
  - createdAt
  - updatedAt
- Add 3 sample projects for development.
- Display each sample project in a project card.
- Each card should show:
  - name
  - description
  - status
  - priority
- Create reusable components where appropriate.
- Keep the UI clean and responsive.

## Out of Scope

- Adding projects
- Editing projects
- Deleting projects
- Filtering
- localStorage
- Authentication
- Backend/API work

## Acceptance Criteria

- [ ] Default Vite starter content is removed.
- [ ] Dashboard renders successfully.
- [ ] Three sample projects are visible.
- [ ] Project cards display required project data.
- [ ] Layout works at desktop and mobile widths.
- [ ] `npm run lint` succeeds.
- [ ] `npm run build` succeeds.
- [ ] No unrelated functionality is added.
