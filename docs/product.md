# Project Dashboard

## Goal

Build a lightweight dashboard for tracking small software and personal projects.

## V1 Features

Users can:

- view projects as cards
- add a project
- edit a project
- delete a project
- assign a status:
  - Planned
  - In Progress
  - Blocked
  - Complete
- assign a priority:
  - Low
  - Medium
  - High
- filter projects by status
- persist projects in localStorage

## Project Data

Each project should contain:

- id
- name
- description
- status
- priority
- createdAt
- updatedAt

## V1 Constraints

- No authentication
- No backend
- No database
- No external APIs
- No unnecessary dependencies
- Data stored locally in the browser

## UX

The app should:

- work well on desktop and mobile
- make project status easy to scan
- keep project creation and editing simple
- avoid unnecessary complexity
