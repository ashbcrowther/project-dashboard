# Gemini / Antigravity Instructions

AGENTS.md is the canonical development policy for this repository.

Before performing development work:

1. Read AGENTS.md.
2. Read the assigned task document.
3. Inspect only relevant files.
4. Stay within the task scope.
5. Run deterministic verification where possible.
6. Provide a concise completion report.

For investigation-only tasks:

- Do not modify files.
- Identify relevant files and code paths.
- Separate observations from assumptions.
- Keep findings concise.

For review tasks:

- Do not modify code unless explicitly requested.
- Focus on correctness, regressions, security and meaningful missing tests.
- Ignore subjective style issues unless they affect maintainability or correctness.
- Return actionable findings only.
